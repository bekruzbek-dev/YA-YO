# YA-YO AI

Shaxsiy va do'stlar uchun bepul ovqat va sog'lom turmush haqida ma'lumot beruvchi Android ilova.
Obunalar, to'lovlar va reklama yo'q.

## Holat
Bosqich 1: loyiha skeleti, Material 3 mavzusi, pastki navigatsiya, GitHub Actions orqali APK build.

## O'rnatish
1. GitHub'da **Actions** bo'limiga kiring va oxirgi muvaffaqiyatli build'ni oching.
2. **Artifacts** ichidan `YA-YO-release-apk` ni yuklab oling va ZIP'dan chiqaring.
3. `app-release.apk` ni telefonga o'tkazing va oching.
4. Telefon so'rasa, "Noma'lum manbalardan o'rnatish" ruxsatini bering.
